## Traps (hard-won this session)

- **`data-tour-step` is not a settle signal.** It flips at `writeTourState`'s emit, before `revealUpTo` heals and before `routeFor` navigates. Sync on `__atlasTestApi.awaitTourSettled()`. My first back-nav regression test synced on the attribute and passed with the fix reverted — only the revert-check caught it.
- **Always revert-check a regression test.** Two tests this session passed for the wrong reason; one was shipped code (`'Set up your folder'`, a string the app has never rendered).
- **A `disabled` button or `pointer-events: none` fires no hover**, so a `title` on it never shows. The locked sidebar icons use `aria-disabled` and stay inert because nothing binds a handler and they carry no `data-action`.
- **The dock height is now a tax on app space.** `--tour-dock-h` drives both the panel and the shell's reserve. At 1366×768 the app gets 446px, and ~92px inside the dock is pure slack — the copy pass buys real estate back.
- **The landing's button order is two `order` rules**; both placements were shot (`20-landing-above` / `21-landing-below`).
- Full-suite verdicts want a quiet machine: close the inspection Chromium, read `PLAYWRIGHT_EXIT`, never grep the summary. The park/unpark flaky is documented and healed on retry.
